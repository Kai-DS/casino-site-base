# Specifications

Use this directory for project specifications and game design documents.

## Folders

- `production/overall/` - specs for the production app as a whole.
- `production/neonjack/` - production specs for NEON JACK.
- `production/texasHoldem/` - production specs for Texas Hold'em.
- `production/videoPoker/` - production specs for Video Poker.
- `sandbox/overall/` - sandbox-wide specs and notes.
- `sandbox/neonjack/` - sandbox specs and experiments for NEON JACK.
- `sandbox/texasHoldem/` - sandbox specs and experiments for Texas Hold'em.
- `sandbox/videoPoker/` - sandbox specs and experiments for Video Poker.

## Suggested Naming

- `casino-hub-spec-vX.Y.md`
- `SPEC_<FEATURE>_vX.Y.md`
